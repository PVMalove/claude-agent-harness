## 1. Название и локализация
- **Английское название:** block-direct-master.sh (PreToolUse Hook)
- **Русский перевод / Суть:**

```text
Блокировка прямых коммитов и пушей в защищенные ветки (master, main, base_branch, integration/*) согласно правилу "Zero Direct Commits".
```
## 2. Полное описание
Скрипт является pre-hook'ом (PreToolUse) для инструмента выполнения bash-команд. Его основная задача — детерминированно обеспечивать соблюдение правила "Zero Direct Commits" (описанного в `docs/agents/git-workflow.md`), запрещая агенту внесение изменений (коммиты и пуши) напрямую в защищенные ветки.

**Логика работы:**
1. Скрипт читает JSON-вход из стандартного потока ввода (`stdin`) и с помощью регулярного выражения извлекает строку `"command"`.
2. Извлекает значение `base_branch` из конфигурационного файла проекта `.harness/project.json`.
3. Определяет защищенные ветки: `master`, `main`, базовая ветка проекта (`base_branch`) и любые ветки, начинающиеся с префикса `integration/`.
4. Если перехваченная команда содержит `git commit` или `git push`, скрипт проверяет текущую активную ветку (через `git rev-parse`). Если текущая ветка является защищенной, выполнение блокируется.
5. Для команды `git push` дополнительно проверяется целевой рефспек в аргументах команды (например, `git push origin HEAD:master` или `git push origin feature:integration/payments`). Если целевой рефспек указывает на защищенную ветку, выполнение также блокируется, даже если пуш выполняется из разрешенной (issue) ветки.
## 3. Контракты
- **Вход (Input/Brief):** JSON-объект вызова инструмента Bash, передаваемый через стандартный ввод (`stdin`). Ожидается наличие поля `"command"`. Также используется переменная окружения `CLAUDE_PROJECT_DIR` (по умолчанию `.`) для определения пути к репозиторию.
- **Выход (Output/Report):** Возвращает код выхода `0`, если нарушения не найдены (разрешает выполнение команды). При обнаружении попытки коммита/пуша в защищенную ветку возвращает код выхода `2` и выводит сообщение об ошибке в стандартный поток ошибок (`stderr`), прерывая выполнение инструмента.
