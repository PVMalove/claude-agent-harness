## 1. Название и локализация
- **Английское название:** block-dangerous-git.sh
- **Русский перевод / Суть:**

```text
Блокировка опасных Git-команд
```
## 2. Полное описание
Данный скрипт-хук (тип `PreToolUse(Bash)`) отвечает за безусловную блокировку разрушительных команд Git. Он перехватывает выполнение таких команд, как `git reset --hard`, `git clean -f`, `git branch -D`, `git checkout .` и `git restore .`. Скрипт адаптирован из "git-guardrails-claude-code", но намеренно не блокирует `git push` напрямую (защита пушей в основные ветки контролируется отдельно в `block-direct-master.sh`). Логика направлена на защиту локального репозитория от случайной потери незакоммиченных изменений агентом, требуя от пользователя явного подтверждения.
## 3. Контракты
- **Вход (Input/Brief):** Строка (через stdin), содержащая команду в формате `"command": "..."` (обычно передается инфраструктурой агента перед выполнением Bash).
- **Выход (Output/Report):** Возвращает код `0`, если опасных паттернов не найдено. Возвращает код `2` и сообщение в `stderr`, если команда заблокирована.
