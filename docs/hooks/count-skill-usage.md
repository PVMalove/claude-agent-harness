## 1. Название и локализация
- **Английское название:** count-skill-usage
- **Русский перевод / Суть:**

```text
Сбор статистики использования навыков (skills).
```
## 2. Полное описание
Скрипт представляет собой хук, вызываемый перед использованием инструмента (`PreToolUse(Skill)`).
Его основная задача — вести подсчет количества вызовов каждого навыка (skill) для последующего анализа.
Хук работает исключительно в аналитических целях, по принципу best-effort, и никогда не блокирует выполнение основного процесса агента (всегда возвращает код успешного завершения `exit 0`).

Внутренняя логика:
1. Читает данные из стандартного потока ввода (`stdin`), извлекая из них имя вызываемого навыка с помощью `grep` и `sed` (ожидается в формате JSON).
2. Если имя навыка извлечено успешно, проверяет наличие файла `.claude/.skill-usage.json` в директории `CLAUDE_PROJECT_DIR` (или в текущей директории по умолчанию). Если файла нет, создает его с пустым JSON-объектом `{}`.
3. Читает текущее количество вызовов для данного навыка из файла.
4. Увеличивает счетчик вызовов на 1.
5. Обновляет файл статистики с помощью `sed`: если навык встречается впервые, добавляет новую пару "ключ-значение", если навык уже существует — обновляет значение счетчика.
## 3. Контракты
- **Вход (Input/Brief):** JSON-данные из `stdin`, содержащие поле `"skill"` с именем вызываемого навыка. Опциональная переменная окружения `CLAUDE_PROJECT_DIR`.
- **Выход (Output/Report):** Всегда возвращает `exit 0`. Создает или обновляет файл `.claude/.skill-usage.json`, сохраняя обновленную статистику по навыкам.
