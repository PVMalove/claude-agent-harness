## 1. Название и локализация
- **Английское название:** require-qa-gate.sh
- **Русский перевод / Суть:**

```text
Блокировка создания PR без успешного прохождения QA
```
## 2. Полное описание
Данный хук типа `PreToolUse(Bash)` предназначен для перехвата выполнения команд в bash-терминале агента. Его основная задача — заблокировать выполнение команды `gh pr create` (создание pull request), если агент предварительно не выполнил успешную проверку текущего состояния рабочего дерева с помощью навыка `qa-gate`.

Хук анализирует входные данные (содержимое bash-команды из stdin). Если обнаружен вызов `gh pr create`, он формирует хэш текущего состояния репозитория (хэш HEAD + хэш текущих изменений) и проверяет наличие и содержимое файла-маркера `.claude/.qa-gate/passed`. Этот маркер создается навыком `qa-gate` при его успешном выполнении. Если маркер отсутствует или его содержимое не совпадает с вычисленным состоянием, хук прерывает выполнение с ошибкой, выводя сообщение о необходимости запуска `qa-gate`. Если команда не является `gh pr create` или проверка пройдена успешно, хук завершается с кодом 0, разрешая выполнение команды.
## 3. Контракты
- **Вход (Input/Brief):** Входной поток (stdin), содержащий bash-команду. Текущее состояние git-репозитория (HEAD и незакоммиченные изменения).
- **Выход (Output/Report):** Код возврата `0` (разрешение выполнения) или код возврата `2` с выводом сообщения об ошибке в `stderr` (блокировка команды).
