## 1. Название и локализация
- **Английское название:** block-pr-merge (PreToolUse Hook)
- **Русский перевод / Суть:**

```text
Запрет автослияния PR / Блокировка выполнения агентом команды `gh pr merge` для обеспечения ручного контроля слияния.
```
## 2. Полное описание
Данный скрипт является перехватчиком (PreToolUse хуком для Bash), который реализует политику "Zero Auto-Merge", описанную в документации рабочего процесса `docs/agents/git-workflow.md`.
Ответственность хука заключается в том, чтобы не дать ИИ-агенту самостоятельно завершить жизненный цикл Pull Request'а путем его слияния.
Внутренняя логика считывает данные из стандартного ввода (stdin) и с помощью регулярных выражений проверяет, не содержит ли поле `"command"` вызов утилиты `gh pr merge`.
Если такая команда обнаружена, хук немедленно прерывает выполнение операции (возвращая код ошибки `2`) и выводит в stderr диагностическое сообщение о том, что слияние веток является исключительной прерогативой разработчика.
## 3. Контракты
- **Вход (Input/Brief):** Текстовые данные (обычно JSON) через стандартный ввод (`stdin`), содержащие параметры планируемого вызова инструмента (например, команду для выполнения в Bash).
- **Выход (Output/Report):**
  - **Успех (Разрешение):** Код возврата `0` (пустой вывод), если запрещенных команд не найдено.
  - **Отказ (Блокировка):** Код возврата `2` и текстовое сообщение в `stderr` с объяснением причины запрета, если обнаружена команда слияния.
