## 1. Название и локализация

- **Английское название:** block-public-attribution
- **Русский перевод / Суть:**

```text
Блокировка AI-атрибуции в публичных Git-метаданных
```

## 2. Полное описание

Скрипт срабатывает на этапе `PreToolUse` для инструмента `Bash`. Его цель — гарантировать, что все Git-коммиты, Pull Request'ы и отправка изменений (push) не содержат упоминаний об использовании ИИ-ассистентов (таких как Claude, ChatGPT, Copilot, Gemini и др.), автоматической атрибуции "Co-authored-by: AI" и ссылок на сессии (session URLs). 

Логика выполнения включает:
1. Безопасный парсинг JSON (через Python) для извлечения выполняемой команды из `tool_input.command`.
2. Определение типа операции (git commit, git push, gh pr / glab mr).
3. При обнаружении этих операций скрипт использует модуль `shlex` (Python) для разбора аргументов команды (например, `-m`, `-F`, `--title`, `--body-file`).
4. Проверка строковых значений и содержимого указанных файлов по регулярному выражению с запрещёнными словами.
5. Для команд push и создания/редактирования PR также дополнительно проверяются сообщения локальных (не отправленных) коммитов (`git log --not --remotes`).
6. В случае нахождения запрещённых подстрок или ошибки чтения файлов/строк, скрипт прерывает выполнение команды, возвращая код ошибки `2` и выводя предупреждение в stderr.

## 3. Контракты

- **Вход (Input/Brief):** JSON-объект, передаваемый на `stdin`, содержащий параметры вызова инструмента (в частности, `tool_input.command`). При необходимости читает файлы сообщений (по путям из аргументов команды) и историю локальных коммитов.
- **Выход (Output/Report):** В случае успешной проверки возвращает код `0` (команда разрешена). В случае обнаружения AI-атрибуции выводит сообщение об ошибке в `stderr` и завершается с кодом `2` (запрет выполнения).
