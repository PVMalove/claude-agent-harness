# tdd — Разработка через тесты

Источник: [`SKILL.md`](../../../skills/first-party/pvmalove/tdd/SKILL.md).
В `pvmalove-suite` этот first-party override заменяет одноимённый vendor-скилл, сохраняя
vendor-снапшот и его provenance неизменными.

Скилл ведёт работу по циклу red → green → refactor на заранее согласованном публичном seam:
один тест проверяет одно наблюдаемое поведение, но может содержать необходимые переходы состояния
и несколько утверждений. Ожидания строятся независимо от production-кода; варианты оформляются
параметризацией, а не условным выбором ожидаемого результата.

Правила отдельно покрывают реальные внутренние компоненты и value objects, команды и query на
внешних unmanaged boundaries, детерминированные часы и RNG, SQL/transactions на production
database engine в изолированном окружении, независимость тестов, именование поведения и
Refactor после Green. Coverage, flaky/seed-политики и обязательная property-based или mutation
инфраструктура целью не являются.
