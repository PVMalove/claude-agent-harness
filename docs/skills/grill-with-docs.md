# Grill With Docs — Прожарь с документами

## 1. Название и локализация

- **Английское название:** `grill-with-docs`
- **Русский перевод:**

```text
Прожарь с документами
```

## 2. Полный перевод текста скила

```text
---
name: grill-with-docs
description: Неумолимое интервью для оттачивания плана или дизайна, в процессе которого также создаётся документация (ADR и глоссарий).
disable-model-invocation: true
---

Запустите сессию `/grilling`, используя навык `/domain-modeling`.
```

## 3. Контракты

- **Вход (Input/Brief):** идея, план или решение в рабочем каталоге.
- **Выход (Output/Report):** уточнённый план и обновлённые ADR/глоссарий при необходимости.
