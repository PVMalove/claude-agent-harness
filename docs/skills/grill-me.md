# Grill Me — Прожарь меня

## 1. Название и локализация

- **Английское название:** `grill-me`
- **Русский перевод:**

```text
Прожарь меня
```

## 2. Полный перевод текста скила

```text
---
name: grill-me
description: Неумолимое интервью для оттачивания плана или дизайна.
disable-model-invocation: true
---

Запустите сессию `/grilling`.
```

## 3. Контракты

- **Вход (Input/Brief):** план, решение или дизайн, которые нужно проверить интервью.
- **Выход (Output/Report):** уточнённые факты, открытые решения и следующий шаг.
