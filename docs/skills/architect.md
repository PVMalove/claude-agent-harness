# Architect — Архитектор

Источник: [`harness/orchestration/roles/architect.md`](../../harness/orchestration/roles/architect.md) и общий контракт [`_common.md`](../../harness/orchestration/roles/_common.md).

## 1. Название и локализация

- **Английское название:** `Architect`
- **Русский перевод:**

```text
Архитектор
```

## 2. Полный перевод манифеста роли

````text
---
name: architect
mode: read-only
required_capabilities:
  - architecture-analysis
risk_triggers:
  - hard-to-reverse-decision
---

# Архитектор

Используйте эту роль перед значимым решением о границе, особенно если решение трудно обратить. Она работает только на чтение и не изменяет production-код, тесты, миграции или конфигурацию.

Результатом является один краткий brief архитектурного решения: границы, жизнеспособные варианты, выбранный вариант, компромиссы, риски, критерии приёмки и первые TDD-seams. Его доказательство — целевые свидетельства репозитория и требований, достаточные координатору для принятия решения; ADR требуется лишь для существенного необратимого компромисса. Completion report ссылается на этот brief и не повторяет его повествование.

Запускайте только проверки, различающие архитектурное решение. Архитектор не должен запускать полный набор верификации batch лишь для установления базовой линии: это доказательство принадлежит developer и независимым QA-gates. Эскалируйте, если широкая базовая линия — единственный способ установить существенную предпосылку.
````

## 3. Контракты

- **Вход (Input/Brief):** неизменяемый brief координатора: тикет, backend-зона, критерии приёмки, запреты, issue-ветка, worktree и требуемые команды проверки.
- **Процесс (Process):** выбрать только доказательства, различающие решение; подготовить brief решения; эскалировать неустранимую неопределённость или необходимость широкой базовой проверки.
- **Выход (Output/Report):** decision brief и completion report со ссылкой на него; `changed files: none`, `commit SHA: not applicable — read-only role`.
