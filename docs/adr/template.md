# Шаблон ADR

Создавайте ADR только для действующего труднообратимого решения с существенным компромиссом.
Номер — следующий после наибольшего номера в каталоге; не переиспользуйте номера удалённых или
отменённых решений. Заголовок формулирует само решение одной фразой.

```markdown
# {Короткое решение}

## Контекст

{Какая постоянная потребность или ограничение требует решения.}

## Решение

{Что является контрактом готового продукта.}

## Альтернативы

{Какие варианты сравнивались.}

## Почему не они

{Почему каждый вариант не выбран.}

## Последствия

{Обязательства и компромиссы, которые следуют из решения.}
```
