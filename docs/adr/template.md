# Шаблон ADR

Скопируйте всё ниже разделителя в `docs/adr/{следующий номер}-{slug}.md` — номер идёт по порядку
в каталоге (следующий за самым большим существующим, включая отменённые решения — номер не
переиспользуется) и не запрашивается заранее устно. Обязательны все пять секций ниже. Язык — как
у остальной документации репозитория (сейчас русский; для англоязычного форка — английский).
Заголовок — само решение одной фразой, а не тема и не номер ADR (см. `0001`-`0005` в этом каталоге).

Решения `0001`-`0005` предшествуют этому шаблону и его секции не повторяют — не переписывать их
задним числом под новую форму.
