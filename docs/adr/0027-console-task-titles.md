# Название задачи из трекера на главной консоли

## Контекст системы

Строка рабочей сессии в принятом макете показывает название задачи, которого нет в batch.
По решению владельца в #748 консоль читает актуальное название из трекера, вместо сохранения
копии при `batch create`. Это разрешённое исключение из прежнего ограничения главной
локальными фактами: ответ трекера является фактом, демонстрационные названия — нет.

## Действующий контракт

Главная сразу показывает локальные сессии и отдельно читает названия в фоновом потоке при
монтировании и действии «Онлайн» (`o`). Офлайн-проверка (`r`), возврат из раздела, смена
языка, ширины или фокуса не запускают чтение названий. Режим offline/online в блоке health
по-прежнему относится к проверкам health; контракт `harness health` не меняется.

Трекер определяется через единый резолвер (ADR 0011), GitHub/GitLab адресуются явно через CLI.
Набор уникальных числовых ID текущих незавершённых сессий имеет общий бюджет запросов 10 секунд.
Запуск неинтерактивный. При ошибке, отсутствии CLI, сети, доступа или названия строка сохраняет
прежний вид. Результаты хранятся только в памяти экрана; новый проход заменяет прежние результаты,
устаревшие ответы не применяются после смены проекта, размонтирования или нового прохода.

Название показывается на исходном языке, буквально и одной строкой. В широком терминале
средняя колонка имеет вид `dispatch_id · название`, с многоточием при нехватке места;
длинный ID сокращается отдельно до 16 символов, чтобы UUID не скрывал название целиком;
ниже `brand.NARROW_WIDTH` название скрывается. Статус, время и выбор сессии сохраняются.

## Операционные последствия

Консоль остаётся read-only; lifecycle, approval, права, команды оркестрации и authority
(ADR 0020–0021) не меняются. Чтение ledger остаётся локальным; нового поля batch и миграции
схемы нет. Старые batch без названия продолжают читаться. Русские названия не переводятся
при EN-интерфейсе. Сеть недоступна — главная работает без названий; постоянный кеш не создаётся.
