# pr-composer — составление тела PR

## 1. Название и локализация

- **Исходный агент:** [`harness/project/agents/pr-composer.md`](../../harness/project/agents/pr-composer.md)
- **Русский перевод:** подготовка описания Pull Request по шаблону проекта.

## 2. Полное описание

Агент получает номер issue, точную целевую ветку, scratch-путь и результат последнего
`qa-gate`. Он читает шаблон из `docs/agents/git-workflow.md`, язык из `.harness/project.json`,
собирает diff и журнал коммитов. Для PR в ветку по умолчанию ставит `Closes #<ID>`, для другой
ветки — `Related to #<ID>`. Все разделы шаблона заполняются по фактическому изменению; если
`qa-gate` не выполнялся, это явно отражается в рисках. Готовое тело сохраняется только в
`.harness/.sandboxes/pr_body/pr-body-<issue>-<slug>.md`.

## 3. Контракт

- **Вход:** issue ID, target branch, путь файла и доступный QA-результат.
- **Выход:** только путь к готовому файлу. Публикацию PR выполняет вызывающая сессия после
  отдельного подтверждения разработчика.
