# code-review-spec — проверка по спецификации

## 1. Название и локализация

- **Исходный агент:** [`harness/project/agents/code-review-spec.md`](../../harness/project/agents/code-review-spec.md)
- **Русский перевод:** независимая проверка соответствия изменения задаче.

## 2. Полное описание

Агент получает команду для diff, список коммитов и путь к спецификации либо её текст. Он
самостоятельно читает недостающий контекст и отмечает пропущенные требования, поведение вне
запрошенного объёма и неверную реализацию кажущегося выполненным требования. Для каждого
замечания цитирует строку спецификации. Вызывается осью Spec скила `code-review`.

## 3. Контракт

- **Вход:** diff, коммиты и спецификация.
- **Выход:** только отчёт до 400 слов без преамбулы.
