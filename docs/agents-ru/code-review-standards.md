# code-review-standards — проверка стандартов

## 1. Название и локализация

- **Исходный агент:** [`harness/project/agents/code-review-standards.md`](../../harness/project/agents/code-review-standards.md)
- **Русский перевод:** независимая проверка diff по стандартам проекта.

## 2. Полное описание

Агент читает diff, список коммитов, найденные файлы стандартов и базовый список code smells.
Он указывает нарушение документированного правила с точным источником и обнаруженные smell
с цитатой изменённого фрагмента. Строгие нарушения отделяются от оценочных замечаний;
проверки, уже выполняемые lint, formatter и type checker, не повторяются. Вызывается осью
Standards скила `code-review`.

## 3. Контракт

- **Вход:** diff, коммиты, стандарты и базовый список smell.
- **Выход:** только отчёт до 400 слов без преамбулы.
