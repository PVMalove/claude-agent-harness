# 1. Название и локализация
- **Английское название:** code-review-spec
- **Русский перевод / Суть:**

```text
Проверка изменений (diff) на соответствие спецификации
```

# 2. Полное описание
Агент `code-review-spec` предназначен для проверки изменений в коде (diff) относительно исходной задачи или спецификации. Он выполняет роль одной из осей оценки в навыке `code-review` (ось Spec) и не предназначен для прямого вызова пользователем. В процессе работы агент анализирует предоставленные изменения, сопоставляет их с требованиями и выявляет неполные реализации, избыточные изменения (scope creep), а также потенциальные ошибки в реализации запрошенных требований. Агент может самостоятельно извлекать недостающую информацию, используя инструменты чтения, командной оболочки и поиска (Bash, Grep, Glob).

# 3. Контракты
- **Вход (Input/Brief):** Команда для получения diff-а, список коммитов и путь к файлу спецификации (или её содержимое).
- **Выход (Output/Report):** Краткий отчет (не более 400 слов, без преамбулы), содержащий:
  (a) невыполненные или частично выполненные требования из спецификации;
  (b) поведение в коде, о котором не просили в задаче (scope creep);
  (c) требования, которые кажутся реализованными, но реализация выглядит неверной.
  Каждое замечание в отчете сопровождается точной цитатой из спецификации.
