1. Название и локализация
- **Английское название:** pr-composer
- **Русский перевод / Суть:**

```text
Генератор описания Pull Request
```

2. Полное описание
Агент `pr-composer` отвечает за формирование текста (тела) для Pull Request (PR) на основе проектных шаблонов, изменений в коде и истории коммитов. Агент не открывает PR самостоятельно и не возвращает текст в ответе. Вместо этого он записывает готовый текст только в `.claude/tmp/pr-body-<issue>-<slug>.md`, чтобы вызывающий агент мог использовать его в команде `gh pr create --body-file <path>`. Вызывающий агент удаляет этот scratch-файл только после успешной публикации; при ошибке сохраняет его для повторной попытки.

**Внутренняя логика и этапы работы:**
1. Получает на вход номер задачи, целевую ветку для сравнения, путь `.claude/tmp/pr-body-<issue>-<slug>.md` и результат последней проверки `qa-gate`.
2. Извлекает язык проекта из `.harness/project.json` (по умолчанию `ru`) и читает шаблон PR из `docs/agents/git-workflow.md` (секция 3).
3. Формирует правильный футер для связи с трекером: `Closes #<ID>` (если целевая ветка является веткой по умолчанию) или `Related to #<ID>` (во всех остальных случаях).
4. Собирает контекст изменений через Git: выполняет `git diff <target-branch>...HEAD` и `git log <target-branch>..HEAD --oneline`.
5. Заполняет все секции шаблона PR. При наличии результатов проверки `qa-gate` они используются в секции верификации. Если `qa-gate` не запускался, об этом явно указывается в секции рисков/ограничений без выдумывания покрытия тестами.
6. Сохраняет сформированный markdown-документ только по переданному scratch-пути, никогда в `docs/tasks/`, используя встроенный инструмент работы с файлами (строго запрещено использовать `bash`, `cat`, `heredoc` для записи).
7. Возвращает вызывающему агенту только путь к созданному файлу без лишних комментариев.

3. Контракты
- **Вход (Input/Brief):** Номер задачи (issue ID), целевая ветка (target branch) для сравнения, путь `.claude/tmp/pr-body-<issue>-<slug>.md` для записи сгенерированного описания, результаты последнего прогона `qa-gate` (если есть).
- **Выход (Output/Report):** Только абсолютный путь к файлу с готовым описанием Pull Request (без преамбул и самого текста в сообщении).
