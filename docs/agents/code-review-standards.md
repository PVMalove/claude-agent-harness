## 1. Название и локализация
- **Английское название:** code-review-standards
- **Русский перевод / Суть:**

```text
Анализатор стандартов кода и выявления запахов кода
```
## 2. Полное описание
Агент отвечает за проверку изменений кода (diff) на соответствие задокументированным стандартам кодирования репозитория и базовому набору "запахов кода" (Fowler smell baseline). Вызывается внутренне компонентом Standards навыка code-review. Не предназначен для прямого вызова.
Агент анализирует предоставленный diff, сверяя его со стандартами. Он четко разделяет жесткие нарушения (задокументированные стандарты) и субъективные оценки (базовые запахи кода), при этом локальные стандарты репозитория имеют приоритет над базовыми запахами. Игнорирует нарушения, которые уже проверяются автоматическими инструментами (lint/format/type-check).
## 3. Контракты
- **Вход (Input/Brief):** Команда получения diff, список коммитов, найденные файлы стандартов репозитория и базовое описание запахов кода.
- **Выход (Output/Report):** Краткий отчет (до 400 слов, без преамбулы) с перечислением нарушений задокументированных стандартов (с указанием файла и нарушенного правила) и найденных запахов кода (с цитированием проблемного участка кода), сгруппированный по файлам/участкам кода.
