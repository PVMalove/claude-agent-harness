Группа «Установка и обновление» (5 команд) убрана из экрана: те же действия есть в пунктах меню «Открыть проект» (1) и «Обновить Harness» (2). Новое по запросу: блоки «Временные файлы» (статистика из плана очистки) и «Worktree» (список из git с защитой активных и свежих, удаление по строке). Из кода экрана: блок «Состояние» (версия, состав, скилы и файлы, lock, оркестрация) и строка использования пайплайна; список команд по пяти группам; панель описания (название, обратимость, CLI, параметры); закреплённый «Вывод»; форма подтверждения с причиной, параметрами и контрольным словом. Новое: группы сворачиваются (раскрыта одна), у групп сводка риска, метка риска у каждой команды с текстом, фильтры «обратимые / с подтверждением». Экран «Оркестрация» построен на том же шаблоне «команды → описание → вывод», поэтому макет подходит и ему (содержимое «Оркестрации» остаётся за #711).
