«Контейнерный запуск →»
Открывает маршрут из шести этапов: Настройка → Preflight → План / approval → Worker → QA → Очистка. Путь в крошках: Главная › Оркестрация › Контейнерный запуск. Проект и выбранный batch сохраняются.
«Открыть восстановление»
Появляется у batch, который core пометил приостановленным или с незавершённой операцией. Вход: история batch → выбранный batch → Восстановление. Показывает причину и последнюю подтверждённую границу до выбора действия. У остальных batch кнопки нет.
